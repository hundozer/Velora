# Interactive Prague Room, 26 October 2026

The room keeps its conversation visible while a right-hand member rail lists active participants. A heartbeat is sent while the room tab is visible, every 30 seconds. A row is considered present for 90 seconds; hiding or leaving the page also attempts to clear it. A crashed browser may remain listed until the timeout. This is a room-specific signal, not the site's broader ten-minute online activity indicator.

The rail respects each member's existing `show_online_status` choice and hides both directions of a block, inactive, unlinked and demo profiles. It uses the profile's `username` when set, with the existing display name as fallback. Clicking a name offers a profile link in a new page or a private message panel over the room. The panel uses the existing authenticated `/api/messages` read and send endpoints, including their recipient and block rules. It does not create a separate chat identity or bypass message permissions.
